# TecnoStore 🛒📱

TecnoStore es una aplicación de **consola en Java** diseñada para gestionar la venta de teléfonos celulares en una tienda minorista.  
El sistema permite administrar **marcas, celulares, clientes, ventas e inventario**, aplicando principios de **Programación Orientada a Objetos**, **JDBC**, **colecciones**, **Stream API** y **patrones de diseño**.

---

##  Tecnologías utilizadas

- Java 17
- Maven
- MySQL
- JDBC
- Apache NetBeans
